# v0.1.5 릴리스 노트 초안 (게시 전 — 사장님 확인용)

> 초안 파일일 뿐이다. 태그·GitHub 릴리스·exe 배포는 다음 카드(③ 릴리스)에서.

## EPUB 글꼴 풀기 v0.1.5

「의견 보내기」 링크를 손봤습니다. 책을 고치는 기능은 그대로입니다.

- **키보드로 쓰기 쉬워졌습니다.** Tab 으로 「의견 보내기」에 오면 글자 뒤가 옅은 파란색으로 바뀌어 지금 어디에 있는지 보입니다. Enter 나 Space 로 엽니다.
- **설명 말풍선이 화면 밖으로 나가지 않습니다.** 창을 화면 끝에 붙이거나 모니터를 여러 대 쓸 때도 말풍선이 그 모니터 안, 창 폭 안에 뜹니다.
- **영어·일본어·중국어 화면은 영어 툴 페이지로 갑니다.** 「의견 보내기」와 새 버전 알림의 「업데이트」가 같은 규칙을 씁니다 — 한국어 화면만 한국어 페이지, 그 밖에는 영어 페이지.
- 영어·일본어·중국어 README 의 의견 링크도 영어 툴 페이지로 바꿨습니다.

의견은 프로그램 위쪽 「의견 보내기」나 [의견 칸](https://chaekgalpi.co.kr/tools/epubfont#feedback)에서 로그인 없이 보낼 수 있습니다(영어: [feedback page](https://chaekgalpi.co.kr/en/tools/epubfont#feedback)). 프로그램은 브라우저로 그 페이지를 열 뿐, 따로 보내는 것은 없습니다.

---

### English

- **Keyboard:** when Tab reaches **Send feedback**, its background turns light blue so you can see where you are; Enter or Space opens it.
- **The tooltip stays on screen**, inside its monitor and the window, even with the window against a screen edge or on a second monitor.
- **One rule for which page opens:** a Korean window opens the Korean tools page; every other language opens the English one — for both Send feedback and the update notice's Update button.
- The English, Japanese and Chinese READMEs now link to the English [feedback page](https://chaekgalpi.co.kr/en/tools/epubfont#feedback).
